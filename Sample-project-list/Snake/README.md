# Snake Demo

更新时间：`2026-05-19`  
适用版本：`0.5.0`

这是 UNU Engine 内置的贪吃蛇示例项目，位于 `Sample-project-list/snake`。

## 功能

- 经典贪吃蛇移动、食物、得分和失败判定。
- `Esc` 暂停菜单。
- 撞墙或撞到自己后自动打开“游戏结束”菜单。
- 难度切换，对应不同移动速度。
- 重置快捷键按钮。
- 使用彩色 Sprite 方块，无外部图片依赖，适合作为脚本和 UI 学习样例。

## 运行

在 Launcher 中选择 `Snake`，或打开该目录作为本地项目。Web 导出会复制本项目的 `assets/` 与 `scenes/`，导出后运行 `PLAY_GAME.bat`。
