# Web Export Capabilities

[中文](EXPORT_WEB.zh-CN.md) | English

Updated: `2026-05-19`  
Version: `0.5.0`

0.5.0 confirms support for multi-scene projects and `sceneCatalog`, nested Scene folder data, full `assets/`, project scripts, scene scripts, HTML UI, item registries, item scripts, audio, images, Prefabs, HTML UI bridge, and `export-report.json`. Run `PLAY_GAME.bat` after export; do not double-click `index.html`. `tests/exportGame.test.ts` validates required files, startup scene, report, and nested script/item/HTML UI resources.
