# UNU Engine 路线图

中文 | [English](ROADMAP.en-US.md)

更新时间：`2026-05-15`

这份路线图用于记录 UNU Engine 从编辑器原型走向可用 2D 游戏开发工具的阶段目标。状态会随功能落地持续更新。

## 阶段 1：编辑器基础体验

目标：让用户能稳定创建、打开、保存和管理项目。

- [x] Electron + Vite + Vue 编辑器壳。
- [x] Launcher 启动界面。
- [x] 历史项目列表。
- [x] 示例项目列表。
- [x] 新建项目窗口。
- [x] 项目重命名和删除。
- [x] 项目另存为。
- [x] 打开其他工程后 Scene View 自动切换。
- [x] 右上角消息弹窗。
- [x] 顶部工具栏分类下拉。
- [x] 场景树实体右键菜单。
- [x] Scene 文件树结构：类文件夹选中、展开/折叠、新建、删除、重命名、复制/粘贴、拖拽移动与嵌套分类。
- [x] 资源树右键菜单。
- [x] 资源树双击文件夹展开/折叠。

## 阶段 2：运行时核心

目标：具备最小可玩的 2D 游戏闭环。

- [x] 播放、暂停、继续、停止。
- [x] 播放态和编辑态选择逻辑分离。
- [x] 播放态禁用部分编辑工具。
- [x] 调试播放开关。
- [x] 输入系统和键鼠映射。
- [x] Camera 组件。
- [x] Background 组件。
- [x] Audio 运行时基础。
- [x] Collider 相对偏移和尺寸。
- [x] `isBlockedRect` 碰撞阻挡检测。
- [x] 场景切换。
- [x] 可交互组件。
- [x] 脚本化交互逻辑。

## 阶段 3：内容生产工具

目标：让关卡、动画、资源和 UI 能被高效编辑。

- [x] Tilemap 基础编辑。
- [x] Tilemap 图形化 Electron 子窗口。
- [x] Tile 值到材质映射。
- [x] Tilemap 多选和批量修改。
- [x] 图片资源预览弹窗。
- [x] 文本资源编辑器。
- [x] 代码高亮。
- [x] 脚本编辑器横向滚动。
- [x] Prefab 保存和实例化。
- [x] 动画帧编辑。
- [x] 动画状态机逻辑。
- [x] 动画状态机图预览。
- [x] UI Text 多行渲染。
- [x] UI Markdown 渲染。
- [x] HTML UI DOM Overlay。
- [ ] Timeline 更完整的关键帧轨道。
- [x] 资源依赖检查与缺失资源自动修复。
- [ ] 未引用资源检测。

## 阶段 4：项目内脚本系统

目标：把游戏逻辑交还给项目，而不是写死在编辑器里。

- [x] 每个项目独立 `ScriptRuntime.ts`。
- [x] 每个项目独立 `InputState.ts`。
- [x] 每个项目独立 `AudioRuntime.ts`。
- [x] 示例项目玩法逻辑迁移到项目脚本。
- [x] Enemy 逻辑不再限定固定 ID。
- [x] Bullet、Door、Chest、背景切换等由项目脚本驱动。
- [x] 打开项目时自动补齐缺失运行时脚本。
- [x] 脚本热重载。
- [x] 脚本 API 提示文档。
- [ ] 更完整的脚本类型提示。
- [ ] 脚本断点调试。
- [x] 脚本错误定位到资源树文件和行号。

- [x] 2D Action Demo。

- [x] 示例双场景门交互。
- [x] 示例背景切换。
- [x] Snake 示例项目。
- [x] 示例内暂停菜单、游戏结束菜单、难度切换和重置快捷键。

## 阶段 6：导出与发布

目标：让项目可以从编辑器走到可分发产物。

- [x] Web 游戏导出。
- [x] 导出目录包含本地 HTTP 启动脚本。
- [x] 导出报告 `export-report.json`。
- [x] 打包版导出从 `resources/dist` 复制，避开 `app.asar` 目录问题。
- [x] Windows NSIS 安装包。
- [x] Windows Portable 包。
- [x] 应用图标、安装器图标、卸载器图标。
- [ ] 一键导出为 ZIP。
- [ ] itch.io 发布模板。
- [ ] GitHub Pages 静态发布模板。
- [ ] Windows 原生游戏壳导出。

目标：支撑更大的项目和更长的迭代周期。

- [x] 碰撞重叠卡顿初步优化。
- [x] 渲染缓存层初步处理。
- [x] 像素贴图采样修正。
- [x] 背景跟随相机卡顿优化。
- [ ] 前端代码拆包。
- [ ] Pixi 渲染对象池。
- [ ] 碰撞空间分区。
- [x] 性能分析面板。
- [ ] 自动化回归测试清单。
- [ ] 项目格式迁移工具。

## 推荐下一步

1. 为 Web 导出添加 ZIP 打包和发布模板。
2. 继续完善脚本类型提示和独立编辑窗口体验。
3. 给 Timeline 增加更完整的关键帧轨道编辑。
4. 增加未引用资源检测和资源清理建议。
5. 建立最小自动化回归测试，覆盖打开项目、切场景、播放、导出。
