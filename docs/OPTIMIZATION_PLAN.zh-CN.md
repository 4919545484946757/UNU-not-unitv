# UNU Engine 小优化计划

中文 | [English](OPTIMIZATION_PLAN.en-US.md)

更新时间：`2026-05-15`

这份计划表聚焦“低风险、高收益、容易验证”的体验优化。它不是长期路线图，而是适合按小步快跑方式持续完成的任务池。

## 执行原则

- 优先修用户每天都会遇到的问题。
- 每项任务都要能用一个明确场景验证。
- 避免一次性大重构，优先做可回退的小改动。
- 修改编辑器体验时，尽量保护播放态和导出流程。

## 近期建议顺序

1. O8：先降低资源缺失风险，尤其是打包和另存为项目后的路径问题。
2. O7：让 Web 导出结果更容易分发。
3. O2：减少新手创建项目时的失败感。
4. O12：让导出闭环更顺。
5. O3：继续提升 Tilemap 大地图编辑体验。
6. O4：让项目内脚本真正适合长期编辑。
7. O6：为后续性能优化提供数据。

## 已完成的重要优化记录

### 2026-05-15 文档、菜单与调试体验

- README、教程、路线图、脚本 API、控制台命令文档已同步到当前功能。
- Snake 示例添加 Esc 菜单、游戏结束菜单、难度切换和重置快捷键。
- 脚本 API 已覆盖 `onPausedUpdate`、`onUiClick`、输入改键和重置快捷键。
- Console 性能页支持默认关闭的详细阶段采样。

### 2026-05-15 脚本与资源稳定性

- 支持项目脚本热重载。
- 脚本错误可定位到资源树文件和行号。
- 资源依赖检查与缺失资源自动修复已接入打开项目和导出流程。


### 2026-05-01 打包与导出稳定性

- 打包版 Web 导出改为从 `resources/dist` 复制，避免 `app.asar/dist` 无法遍历。
- `dist` 已加入 `extraResources`。
- 示例项目和素材已作为 `extraResources` 分发。
- Windows 主程序图标通过 `afterPack` 钩子写入 exe。
- NSIS 安装器和卸载器图标已配置。

### 2026-05-01 示例项目路径稳定性

- 示例项目路径从绝对路径改为相对路径。
- 打开项目时自动检查场景列表。
- 另存为项目时同步修复场景与资源路径。
- 打包版示例项目复制到用户数据目录后再编辑。

### 2026-05-01 播放态体验

- 播放态默认隐藏调试信息。
- 调试播放开关可显示碰撞箱、边界框、网格和实体名。
- 播放态和编辑态选择逻辑分离。
- 播放中暂停、继续、停止流程稳定化。
